# EaseMart

EaseMart is a modern multi-category e-commerce web application built with React, Tailwind CSS, Context API, and React Router. It features responsive design, product filtering, cart management, local storage persistence, search functionality, pagination, a clean user-friendly interface and an efficient state management.

## Live Preview
https://easemart-store.netlify.app/

## Features
- Responsive design
- Product filtering
- Search functionality
- Shopping cart
- Local storage persistence
- Pagination
- Clean and modern UI

## Tech Stack
- React.js
- Tailwind CSS
- React Router
- React Slick
- Context API
- Clerk Authentication

## Installation

```bash
npm install
npm run dev
```
